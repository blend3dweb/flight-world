# AERO: WebGPU

Новая версия находится в отдельной папке `webgpu`. Исходная WebGL-версия сохранена в корне проекта.

## Запуск

Из корня проекта запустить `START-WEBGPU.cmd`. Нужен Node.js; зависимости Three.js уже установлены локально. После копирования проекта без `node_modules`: `npm ci --prefix webgpu`.

Лаунчер поднимает локальный сервер и открывает Chrome (или Edge) с отдельным профилем `.chrome-webgpu` и запросом дискретной видеокарты. Системные настройки и личный профиль браузера не меняются. Профиль `.chrome-webgpu` не включать в архивы исходников.

- Приложение: http://127.0.0.1:8765/webgpu/index.html
- Галерея этапов: http://127.0.0.1:8765/stages/index.html
- Исходная WebGL-версия: http://127.0.0.1:8765/

При ручном запуске: `node serve.cjs` из корня проекта, затем открыть адрес приложения. Поддержка WebGPU и выбор видеокарты зависят от браузера, драйвера и устройства. Новые WGSL-материалы требуют WebGPU; исходная версия остаётся отдельным вариантом для WebGL.

## Управление

WASD / стрелки — самолёт, P — автопилот, пробел — пауза, V — внешний вид, C — кабина, O — облёт самолёта, R — сброс. Во внешнем виде мышь вращает камеру, колесо меняет расстояние. Панель «Небо и погода» задаёт качество, место старта, время суток, длительность суток и погоду. Запись запускается только кнопкой пользователя; автоматические проверки сохраняют PNG, видео не создают.

## Что перенесено

1. Зафиксирована исходная сцена, сохранены снимки и проверки геометрии.
2. Подключён локальный Three.js 0.186.0, WebGPURenderer и узловые материалы; сохранены самолёт, управление, HUD и камеры.
3. Небо, облака в мировых координатах, солнце, закат, луна и звёзды; цикл суток, дождь, снег, плавные переходы погоды. Использованы существующие источники света.
4. Океан: геометрические волны, карта глубины от рельефа, мелководье, пена, отражение города и неба, изменение волн при ветре. Зеркальная камера обслуживает только отражение.
5. Три процедурных типа деревьев с ветвями и листьями, упрощённый дальний лес, ближние пулы деревьев, участки травы с ветром и отсечением по расстоянию.
6. Шесть архитектурных семейств, фасадные рёбра и пояса, парапеты и оборудование крыш. Сохранены непрямоугольная бухта, разнонаправленные дороги, входы, скамейки, набережная, мост и аэропорт. Доля ночных окон уменьшена вдвое: 0.55 → 0.275.
7. Сокращены группы отрисовки леса, добавлены дистанционное отключение деталей и профили качества. GPU-кадр больше не копируется на CPU для каждого обновления HUD; объединение выполняется только при снимке или записи.

Это процедурная сцена: архитектура и растительность остаются стилизованными. Волны — сумма шести аналитических составляющих, не FFT; трава анимируется вершинным шейдером, без отдельного compute-симулятора. У снега нет накопления, у зданий нет интерьеров. Фотореалистичные модели и текстуры из приведённых референсов не импортировались.

## Проверки и снимки

Из корня проекта при запущенном сервере:

```powershell
$env:FLIGHT_GPU='nvidia'
node stage-review.cjs 07-final
node gpu-audit.cjs 07-final
node gpu-city-audit.cjs 07-final
node gpu-benchmark.cjs
```

Скрипты используют Playwright из установленного Codex runtime (путь указан в первой строке каждого `.cjs`). Для другой машины заменить его на `require('playwright')` после установки Playwright. `stage-contact.py` требует Python и Pillow.

В `stages/01-baseline` … `stages/07-final` находятся PNG, `report.json`, галереи и контрольные копии исходников `source`. Для запуска отдельного WebGPU-контрольного состояния скопировать `source` в отдельную директорию, выполнить в ней `npm ci` и обслуживать HTTP-сервером; node_modules не дублируется в каждом архиве.

`report.json` содержит функциональные проверки и короткую диагностику времени кадра без видимого окна, а не гарантированный FPS. `gpu-audit.json` проверяет GPU-маску окон, стабильность облаков при повороте, реальные отражённые пиксели города и ресурсы при смене погоды. `geometry-audit.json` проверяет дороги, кварталы, входы, рельеф, аэропорт и отсутствие растительности на зарезервированных участках. `benchmark.json` содержит отдельный прогон живого приложения в видимом Chrome 1920×1080 и длительную смену суток/погоды. В отчётах указан фактически выбранный адаптер: результаты Intel и NVIDIA напрямую не сравнивать.

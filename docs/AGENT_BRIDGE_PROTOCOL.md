# Flight World Agent Bridge — протокол 0.1.0

Дата начала реализации: 20.09.2026.

Agent Bridge предоставляет нейромодели программный вход в работающую WebGPU-сцену. Первый прототип работает внутри страницы через `window.flight.agent`. Он не записывает видео или изображения на диск: визуальное наблюдение создаётся по запросу в отдельном WebGPU render target, читается в память и возвращается вызывающему процессу.

## Доступ

После события `window.flightReady === true` доступны:

```js
const agent = window.flight.agent;
const capabilities = agent.capabilities();
const observation = await agent.observe({ visual: true, width: 512, height: 288 });
const response = await agent.dispatch({ type: 'world.query', payload: { semantic: 'bridge' } });
```

Версия протокола передаётся в `capabilities().protocol` и в каждом наблюдении. Команда имеет поля `id`, `type` и `payload`. Ответ `dispatch()` содержит исходный `id`, признак `ok`, тип команды и результат.

## Реализованные команды

| Команда | Назначение |
| --- | --- |
| `ping` | Проверка доступности и получение возможностей моста |
| `observe` | Состояние мира, камеры, телеметрия, ближайшие объекты и необязательный RGB-кадр |
| `observer.set` | Положение, цель и угол обзора независимой камеры агента |
| `observer.moveToObject` | Переход к объекту по ID, имени или семантической категории |
| `world.query` | Поиск объектов по имени и категории |
| `world.raycast` | Луч из камеры агента либо из заданной точки и направления |
| `world.identifyPixel` | Связь координаты пикселя с объектом, категорией и исходным модулем |
| `environment.set` | Время суток, погода и автоматические циклы |
| `flight.start` | Перенос полёта в город, аэропорт или к островам |
| `quality.set` | Уровень качества сцены |
| `simulation.pause` | Пауза или продолжение симуляции |
| `simulation.step` | Управляемый шаг симуляции |

Пример команды:

```js
await agent.dispatch({
  id: 'inspect-bridge',
  type: 'observer.set',
  payload: {
    position: [-1350, 430, -720],
    target: [-2000, 60, -1900],
    fov: 58
  }
});
```

## Датчики первого прототипа

- RGB framebuffer по запросу с ограничением размера 64–1280 × 64–720 пикселей;
- линейная глубина во view space, нормали во view space и точный object-ID buffer по запросу;
- семантический каталог объектов со стабильными ID в пределах жизни страницы;
- координаты и тип объекта, число экземпляров и вершин, связанный исходный модуль;
- raycast с точкой пересечения и расстоянием;
- состояние самолёта, камеры, океана, времени и погоды;
- число draw calls, треугольников, линий и точек;
- среднее и 95-й процентиль времени CPU-подачи кадра;
- сведения о графическом адаптере.

Визуальное наблюдение возвращает RGB как JPEG, а depth, normal и object ID как lossless PNG только в память. Поля `meanLuminance` и `luminanceStdDev` позволяют автоматически отличить содержательный проход от пустого или чёрного буфера. Object ID кодируется как `r + (g << 8) + (b << 16)` и совпадает со стабильным ID семантического каталога.

## Семантические категории

Первый словарь содержит `aircraft`, `ocean`, `bridge`, `airport`, `road`, `vegetation`, `building`, `city`, `terrain`, `atmosphere`, `light`, `camera` и `world`. Категория и исходный модуль определяются по явно заданным метаданным или по имени объекта и его родителей.

Поиск поддерживает невидимые в текущем кадре объекты через `visible: false`. Это нужно агенту для перемещения к объекту, который временно отключён системой дальности детализации.

## Ограничения версии 0.1.0

- Нет GPU timestamp query; поле `gpuTimingAvailable` равно `false`.
- Нет постоянного внешнего процесса и памяти маршрута между перезапусками страницы.
- Нет автономного изменения исходного кода.
- Захват RGB выполняется только по команде и создаёт дополнительный проход рендера.

Следующий подэтап: добавить постоянный локальный управляющий процесс, память маршрута, автономный обход локаций и повторную проверку после изменения сцены.

## Проверка

Команда:

```powershell
node agent-bridge-audit.cjs
```

Проверка не сохраняет изображение. Она подтверждает протокол, каталог океана и моста, независимую камеру, raycast, управление погодой и паузой, чтение RGB/depth/normal/object-ID проходов и отсутствие ошибок страницы. Дополнительно ID центрального пикселя сверяется с независимым raycast. Машиночитаемый результат: [verification/agent-bridge-smoke.json](verification/agent-bridge-smoke.json).

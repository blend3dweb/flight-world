# Нейромодель и контроль разработки

Принятое рабочее решение:

- `qwen3.5:4b` выполняет роль глаз и диспетчера;
- Codex контролирует процесс, данные, исходный код и результаты проверок;
- `qwen3.5:9b` остаётся выключенным резервом для отдельных сложных случаев.

Настройки находятся в [agent-model-config.json](../agent-model-config.json), а обязательный формат результата 4B — в [agent-defect.schema.json](../agent-defect.schema.json).

## Поток данных

```text
WebGPU-сцена
  → Agent Bridge: RGB + depth + normal + object ID + телеметрия
  → qwen3.5:4b: визуальное описание и список возможных дефектов
  → структурированный JSON
  → Codex: проверка доказательств и связь с исходным кодом
  → изменение кода и автоматические тесты
  → Agent Controller: возврат в ту же точку
  → qwen3.5:4b + Codex: проверка результата
```

## Обязанности 4B

Модель наблюдает сцену, находит возможные отклонения, указывает координату, object ID, семантическую категорию и предполагаемый модуль. Она оценивает уверенность и выбирает одно решение:

- `pass` — заметных отклонений нет;
- `reinspect` — нужен другой ракурс или дополнительный сенсор;
- `dispatch-to-codex` — есть проверяемый дефект с доказательствами.

4B не редактирует файлы, не выполняет Git-команды и не публикует сборку.

## Обязанности Codex

Codex проверяет каждый вывод модели по объектным данным, телеметрии и исходному коду. Неподтверждённые предположения отклоняются или отправляются на повторный осмотр. Подтверждённая проблема превращается в изменение кода с проверкой сборки и повторным маршрутом.

Решение о качестве строится не только на ответе 4B. Требуется совпадение нескольких источников:

- визуальное наблюдение;
- object ID или raycast;
- связанный модуль кода;
- телеметрия либо воспроизводимое состояние;
- повторная проверка после исправления.

## Использование 9B

`qwen3.5:9b` не загружается автоматически. Его можно вручную вызвать, если 4B несколько раз возвращает низкую уверенность или не различает сложную визуальную причину. Перед запуском 9B модель 4B должна быть выгружена из Ollama. Codex всё равно проверяет итоговый вывод 9B.

## Хранение данных

Сырые изображения не сохраняются в постоянную память. Сохраняются структурированные находки, координаты, object ID, модуль, сенсорные метрики, решение модели и результат проверки Codex. Это позволяет воспроизводить ход разработки без накопления кадров и видео.

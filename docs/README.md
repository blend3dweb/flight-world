## Запуск

Из папки проекта запустить `START-WEBGPU.cmd`. Он открывает Chrome/Edge с отдельным профилем и запросом дискретной видеокарты.

Адрес сцены: http://127.0.0.1:8765/webgpu/index.html

Адрес галереи: http://127.0.0.1:8765/stages/index.html

Исходная WebGL-версия: http://127.0.0.1:8765/

## Основные файлы

| Путь | Назначение |
| --- | --- |
| `webgpu/flight.js`, `aircraft.js` | Сцена, самолёт, полёт, HUD и существующие камеры |
| `webgpu/ocean.js` | Вода, волны, глубина и отражения |
| `webgpu/vegetation.js` | Деревья, трава, ветер и детализация по расстоянию |
| `webgpu/city.js`, `city-details.js`, `materials.js` | Архитектура и материалы |
| `webgpu/city-layout.js`, `urban-plan.js` | Рельеф города, улицы, кварталы и инфраструктура |
| `webgpu/atmosphere.js`, `sky-nodes.js`, `precipitation.js` | Небо, сутки и погода |
| `stages/01-baseline` … `07-final` | Снимки, тесты и контрольные исходники завершённого переноса |
| `stage-review.cjs`, `gpu-audit.cjs`, `gpu-city-audit.cjs`, `gpu-vegetation-audit.cjs`, `gpu-benchmark.cjs` | Автоматические проверки |
| `reference`, `reference-review-v2` | Сохранённые материалы разбора видеореференсов |
| `.chrome-webgpu` | Локальный профиль браузера; не включать в публикации и архивы исходников |

Старые MP4 и ZIP сохранены как история предыдущих версий. При переносе новое видео не создавалось. Запись нового видео — только по отдельной команде пользователя после проверки сцены.

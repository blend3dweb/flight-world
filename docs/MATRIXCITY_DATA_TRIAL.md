# MatrixCity: источник для ограниченной пробы

Статус на 04.10.2026: данные подготовлены, Splatfacto обучен на одном блоке и Gaussian-ассет экспортирован в локальную папку `data/matrixcity/exports/block_3_final/`. Замкнутой mesh-геометрии зданий и подключения к WebGPU **ещё нет**. Квартал MatrixCity `small_city/aerial/train/block_3` выбран как один виртуальный участок с согласованными изображениями, глубиной и положениями камер. Это не квартал ID 12 существующей Океании: сопоставление систем координат и замена участка — отдельная работа.

## Получено локально

- 256 RGB PNG в исходном архиве; 185 кадров выбраны опубликованным `transforms.json`.
- 256 float32 EXR-карт Z-глубины из соответствующего архива; для всех 185 кадров проверена пара с RGB и камерой.
- `transforms.json` в формате Nerfstudio с исходными координатами в метрах, восстановленной матрицей поворота и ссылками на RGB/depth.
- Выборочное облако `depth_sampled_init.ply`: 676 800 точек из 47 видов с шагом 12 пикселей. Его границы приблизительно X −404…404 м, Y −890…−331 м, Z −3…263 м.
- Для Splatfacto создана отдельная копия 185 RGB-кадров в 960×540 с пересчитанными фокусными расстояниями и центром кадра: `data/matrixcity/training/small_city_block_3_half/`. Положения камер и начальное облако сохранены; EXR остаются в исходном подготовленном наборе.

Исходные и подготовленные файлы лежат в `data/matrixcity/` и исключены из Git. SHA-256 обоих архивов сверяется скриптом загрузки с хешами источника. Для повторения: `python tools/fetch-matrixcity-block.py`, затем `python tools/prepare-matrixcity-block.py`. Для облака нужен изолированный Python с `numpy`, `OpenEXR`, `opencv-python-headless`; команда: `data/matrixcity/.venv/Scripts/python.exe tools/build-matrixcity-pointcloud.py`.

## Отдельное окружение обучения

На Windows подготовлены отдельные Python 3.11.17 и виртуальное окружение `data/matrixcity/train-env/`: PyTorch 2.7.1+cu128, torchvision 0.22.1+cu128, Nerfstudio 1.1.5 и gsplat 1.4.0. CUDA 12.8 `nvcc` находится в `data/matrixcity/cuda-min/Library`, C++ Build Tools 2022 — в системной установке Visual Studio. PyTorch успешно распознал RTX 5050 Laptop GPU (CUDA compute capability 12.0) и выполнил тестовое умножение матриц на GPU. Набор для обучения создаётся командой `data/matrixcity/.venv/Scripts/python.exe tools/prepare-matrixcity-training.py`.

В первом запуске `gsplat` компилирует CUDA-расширение. Для ноутбука с 16 ГБ RAM сценарий `tools/train-matrixcity.cmd` задаёт `MAX_JOBS=1`, `CMAKE_BUILD_PARALLEL_LEVEL=1`, `TORCH_CUDA_ARCH_LIST=12.0`, пути CUDA и Visual C++ и кодировку UTF-8. Параллельная сборка в 10 процессов исчерпала RAM и была остановлена; последовательная завершилась. Минимальный CUDA-пакет хранит `cudart.lib` в `Library/lib`, поэтому сценарий добавляет эту папку в `LIB`.

Запуск из корня проекта: `tools\train-matrixcity.cmd 3000 matrixcity-block3-train`. При продолжении третий аргумент — каталог с `.ckpt`; например `tools\train-matrixcity.cmd 1000 matrixcity-block3-resume-check C:\...\nerfstudio_models`. Nerfstudio считает первый аргумент числом **дополнительных** шагов при продолжении, а глобальный номер шага показывает отдельно. Крупные файлы окружения, входных данных, логов, чекпоинтов и экспорта не входят в Git.

С Nerfstudio 1.1.5 и PyTorch 2.7.1 потребовались две правки **только в изолированном окружении**: явно разрешить чтение локально созданного чекпоинта (`torch.load(..., weights_only=False)`) и заново привязать оптимизаторы к параметрам Splatfacto после загрузки чекпоинта. Без второй правки продолжение увеличивало счётчик шагов, но не меняло веса; такой диагностический прогон не используется. Воспроизвести патч после установки окружения: `data/matrixcity/train-env/Scripts/python.exe tools/patch-nerfstudio-torchload.py`. Выполнять его только для доверенных собственных чекпоинтов.

## Обучение и результат

- Проверка: 10 шагов и сохранённый чекпоинт; затем пробный прогон 3000 шагов за 136 с чистого времени обучения. Экспорт пробы: `data/matrixcity/exports/block_3/splat.ply` (192 МБ).
- Исправленное продолжение: ещё 1000 шагов с проверкой фактического изменения координат, цветов и непрозрачности; затем ещё 16 000 шагов. Итоговый чекпоинт `data/matrixcity/outputs/matrixcity-block3-final/splatfacto/2026-10-04_194005/nerfstudio_models/step-000019999.ckpt` (559 МБ). Итоговый бинарный PLY: `data/matrixcity/exports/block_3_final/splat.ply` (190 853 713 байт, 769 565 гауссиан после фильтрации, SHA-256 `92342D8012292408ED377C2C7AEFE26F2E4C7D0B5E2D9DC2C9DE367DCEB7747E`).
- На контрольных видах при 2000 шагах: PSNR 21,62 дБ, SSIM 0,600, LPIPS 0,338. При 19 000 шагах: PSNR 30,96 дБ, SSIM 0,918, LPIPS 0,059. Это качество восстановления изображений выбранного блока; значения не описывают качество лётной сцены или её FPS.
- Число гауссиан в итоговой модели — 775 030 до фильтрации экспорта. Пиковая память, зафиксированная PyTorch во время обучения, около 4,3 ГБ. Модель и большие данные лежат в игнорируемом `data/matrixcity/`, в Git не включаются.

Источники: [описание MatrixCity](https://github.com/city-super/MatrixCity), [файлы блока](https://huggingface.co/datasets/BoDai/MatrixCity/tree/main/small_city/aerial/train), [документация Nerfstudio по данным](https://docs.nerf.studio/quickstart/data_conventions.html). Лицензия **самого датасета**, указанная авторами, — [CC BY-NC 4.0](https://city-super.github.io/matrixcity/); он пока пригоден только для некоммерческой локальной пробы. Лицензия кода репозитория отличается от лицензии датасета.

## Что следует сделать

1. Восстановить отдельную пригодную для коллизий и object-ID mesh-геометрию. Облако точек содержит выборки поверхности по видимым лучам, но не замкнутые здания и не семантику; на границах объектов depth могут быть артефакты сглаживания. EXR-глубина в исходнике хранится в сантиметрах: коэффициент для перевода в метры 0,01.
2. Совместить координаты mesh и сплатов, ограничить загрузку одним сектором, проверить FPS и задержки на маршруте этапа 15.1. Прежде чем распространять данные в серверной сборке, подобрать разрешённый для этого источник либо получить права.

Видео и демонстрационные рендеры для этой пробы не создаются.

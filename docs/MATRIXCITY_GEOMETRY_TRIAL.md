# MatrixCity: геометрия пробного сектора

Статус: из depth-карт MatrixCity Small City aerial block_3 восстановлен **mesh видимых поверхностей**. Он проверен на ракурсах, не участвовавших в слиянии, и совмещён с обученным Gaussian-ассетом. Это ещё не замкнутая модель зданий для коллизий и не источник индивидуальных ID объектов.

## Воспроизведение

Использовано отдельное `data/matrixcity/geometry-env/` с Python 3.11.17, Open3D 0.19.0, OpenEXR 3.5.2, OpenCV 5.0.0.93 и NumPy. Open3D 0.20.0 при пробе возвращал пустой TSDF-mesh для float32 глубины в метрах; [отчёт об этой ошибке](https://github.com/isl-org/Open3D/issues/7592) указывает на изменение нормализации глубины. Обучающее окружение Nerfstudio не переустанавливалось.

Из корня проекта:

```powershell
data/matrixcity/geometry-env/Scripts/python.exe tools/reconstruct-matrixcity-mesh.py
data/matrixcity/geometry-env/Scripts/python.exe tools/align-matrixcity-mesh.py
data/matrixcity/geometry-env/Scripts/python.exe tools/validate-matrixcity-mesh.py
```

Реконструкция берёт 47 разнесённых по траектории видов, уменьшает EXR-глубину до 480×270, переводит сантиметры в метры и сливает выбранный сектор `X −120…0, Y −620…−500, Z −5…180 м` с шагом TSDF 0,75 м. RGB используется для обучения внешнего вида, а mesh извлекается только из depth и камер. Координаты исходного mesh — метры MatrixCity, ось Z направлена вверх. Сохранённое преобразование Nerfstudio переводит его в систему координат обученного Gaussian-ассета.

Результаты находятся в исключённой из Git папке `data/matrixcity/geometry/block_3_roi/`:

- `visible_surfaces_source.ply` — 69 476 вершин, 132 027 треугольников, координаты источника.
- `visible_surfaces_splat.ply` — тот же mesh в координатах Gaussian-ассета.
- `mesh_metadata.json`, `alignment_metadata.json`, `validation.json` — параметры и численные проверки.
- `matrixcity-building-001-collider.ply`, `collision_metadata.json`, `collision_validation.json` — замкнутый коллизионный объём одного полного контура, его ID и проверки.

На 12 контрольных ракурсах, не использованных при слиянии: покрытие лучей внутри сектора — **99,0%**, медианная ошибка Z-глубины — **0,31 м**, p95 — **1,80 м**. Площадь треугольников, похожих по нормали на крыши, составляет около 13 711 м², на фасады — около 12 469 м². Медианное расстояние от вершины mesh до ближайшего центра обученного гауссиана — 0,52 м; p95 — 2,87 м. Это проверка совмещения, а не доказательство точности каждого фасада.

## Граница результата

Mesh видимых поверхностей не замкнут. Отдельно из плотной карты высот получен консервативный замкнутый коллизионный объём для полного контура `matrixcity-building-001` площадью 2 312 м², с основанием 0,90 м и верхней границей 44,62 м. Он прошёл проверку объёма, самопересечений и 100 лучей к крыше. Соседний массив касается границы сектора и объединяет несколько высот; он исключён из индивидуальных коллизий и ID. Для повторения: `data/matrixcity/geometry-env/Scripts/python.exe tools/build-matrixcity-colliders.py`, затем `data/matrixcity/geometry-env/Scripts/python.exe tools/validate-matrixcity-colliders.py`.

Аэросъёмка не гарантирует наблюдение входов, нижних частей фасадов и интерьеров; их геометрию нельзя объявлять восстановленной из этих данных. Коллизионный объём — упрощённый защитный proxy, а не детальная архитектурная модель. Остальные здания и семантика требуют отдельной работы. Данные MatrixCity остаются локальной пробой: вопрос прав на публичное использование фиксируется отдельно в [плане](DEVELOPMENT_PLAN.md).

## Локальная WebGPU-проверка

Открыть `http://127.0.0.1:8765/webgpu/index.html?matrixcity=1` после запуска `START-WEBGPU.cmd`. В панели «Небо и погода» появится переключатель между процедурной Океанией и геометрией MatrixCity, а после загрузки появится кнопка пробного Gaussian-слоя. Подгрузка идёт из исключённой из Git папки `data/matrixcity/geometry/block_3_roi/`; обычный адрес приложения и публичная сборка не загружают эти данные. Исходные координаты переводятся из Z-up в Y-up с единичным масштабом и общим смещением для видимой поверхности и коллайдера. Вершинные атрибуты PLY переводятся из `float64` в `float32` для WebGPU. Материал mesh пока нейтральный; Gaussian-режим описан отдельно.

Проверка `node tools/verify-matrixcity-web.cjs` проходит без сохранения изображения: в браузере загружается 69 476 вершин, 132 027 треугольников видимого mesh и 76 треугольников коллайдера; переключение и возврат работают, Agent Bridge находит `matrixcity-building-001` и raycast пересекает proxy. Пока переключается **вся группа существующего города**, а не отдельный квартал. Пробный Gaussian-слой описан [отдельно](MATRIXCITY_GAUSSIAN_WEB_TRIAL.md); далее — точечная замена и сравнение на одной траектории.

Видео и демонстрационные рендеры не создавались.

# MatrixCity: локальная Gaussian-проба в WebGPU

Исходный экспорт Splatfacto содержит 769 565 примитивов и занимает около 191 МБ. Скрипт `tools/prepare-matrixcity-web-splats.py` преобразует их в ограниченный вариант для выбранного сектора: 67 915 центров внутри ROI, максимум 30 000 после пространственной выборки по ячейкам 2 м с приоритетом непрозрачных примитивов. Отброшены коэффициенты SH выше нулевого порядка; результат `data/matrixcity/geometry/block_3_roi/splats_roi_sh0_30k.ply` занимает 1,68 МБ. Это оценочный LOD, не полное качество обученного ассета. Файл и обучающие данные исключены из Git из-за размера и лицензии MatrixCity CC BY-NC 4.0.

В `?matrixcity=1` после локальной загрузки появляются кнопки «Геометрия MatrixCity» и «Gaussian». GaussianSplat и GaussianSplatPLYLoader берутся из уже установленного Three.js 0.186.0 и работают в том же WebGPU-рендерере. Сохранённое преобразование Nerfstudio возвращает центры и ковариации в исходные метры; затем общий поворот Z-up → Y-up и смещение помещают их вместе с mesh и коллайдером. Отдельного постоянно работающего рендерера нет.

`node tools/verify-matrixcity-web.cjs` проверяет загрузку 30 000 примитивов, переходы «Океания → mesh → Gaussian → Океания», 36 кадров в Gaussian-режиме без ошибок страницы/GPU-консоли и доступность коллайдера по ID и лучу. Видеофайлы и снимки не создаются.

Ограничение текущей пробы: видимый mesh скрыт в основном Gaussian-кадре, хотя коллайдер остаётся в структуре сцены. При прямом наблюдении Agent Bridge RGB берётся из Gaussian, затем mesh временно включается для depth/normal/object-ID и снова скрывается. Отдельная проверка четырёх проходов подтвердила три геометрических прохода и совпадение ID центрального пикселя с `world.identifyPixel`; физический raycast сохранил доступ к коллайдеру. Захват сенсоров временно останавливает основной кадровый цикл, чтобы его материалы не менялись во время асинхронного чтения GPU.

Совместная запись глубины mesh+Gaussian **в основном видимом кадре** ещё не проверена. Gaussian прозрачен и не пишет глубину; нужно отдельно решить отсечение за mesh, порядок слоёв и стабильность при повороте камеры. Дневное состояние зафиксировано на 10:00 без погоды. [Покадровое сравнение квартала № 12](STAGE_15_MATRIXCITY_MODES.md) не показало прироста FPS от текущего Gaussian-слоя.
